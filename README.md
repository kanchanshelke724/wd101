# wd101
Registration Form Page

Name: Enter your full name.

Email: Enter a valid email address.

Password: Choose a secure password.

Date of Birth: Enter your birth date.

Terms & Conditions: Accept the terms to proceed.

Once the form is filled, the details are submitted and displayed in the Entries section below the form. It shows the list of registered users, their email, password, date of birth, and whether they have accepted the terms and conditions.

Features:

Form validation for user inputs.

Displaying submitted entries in a table format for easy tracking.

The ability to manage user registrations.

This feature is designed to streamline the user registration process and store entries for later use in the system.
